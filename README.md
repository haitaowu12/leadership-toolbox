# Leadership Toolbox

Practical help for the next conversation, decision, handoff or team experiment. This is an independently sourced leadership skill and a versioned reading library. It requires no paid API, database or running service.

**Start:** [use the helper](skills/leadership-toolbox/SKILL.md), [choose a method](skills/leadership-toolbox/references/catalog.md), or [browse the docs](docs/index.md).

Ask: “Use leadership-toolbox. Two people want different priorities. Help me prepare a useful next conversation.” A direct question such as “Explain GROW” gets a direct answer. A blank profile is enough.

## Install

Download the reviewed release archive, extract it, then use [installation instructions](docs/installation.md). The complete installable folder is `skills/leadership-toolbox`; keep its references, templates and scripts together. Hosts that support local `SKILL.md` discovery may load that folder. Other assistants can read the entrypoint manually. Installation does not grant permission to message people, assign work or change systems.

## What is included

- Fourteen practical methods and six situation guides, with stable IDs.
- A short decision workflow, conversation/practice templates and source notes.
- Optional private profile and practice records stored outside the shared package.
- Standard-library Python installation, validation and release helpers.

[Evidence and measurement](docs/evidence-and-measurement.md) distinguishes useful observations from claims about effectiveness. [Validation](docs/validation.md) states what has actually been tested. [Contributing](CONTRIBUTING.md) explains how to propose a change.
