# Useful sequences, with transition conditions

Use a sequence only when one output makes the next action possible. Prefer one useful next move over a workshop bundle. Stop the sequence when the underlying problem is resolved or the next card is ineligible.

| Situation | Sequence | Transition condition and owner |
|---|---|---|
| Conflicting assignments | [L09 capacity](methods/L09-capacity.md) → [L01 delegation](methods/L01-delegation.md) | Authorised priority owner releases realistic time; recipient accepts the bounded responsibility |
| Unclear recurring expectations | [L30 listening](methods/L30-structured-listening.md) → [L15 working agreements](methods/L15-team-charter.md) | Accounts and changeable norms are clear; team can genuinely revise them |
| A solution prescribed too early | [L26 framing](methods/L26-problem-framing.md) → [L29 alternatives](methods/L29-decision-analysis.md) | Decision owner accepts the problem and criteria; credible alternatives exist |
| Recurring delays across roles | [L21 process map](methods/L21-process-map.md) → [L20 hypotheses](methods/L20-fishbone.md) → [L08 test](methods/L08-pdsa.md) | Work performers verify the relevant route; investigator narrows a hypothesis; authorised test owner verifies a bounded recovery path |
| Many initiatives, weak rationale | [L19 drivers](methods/L19-driver-diagram.md) → [L24 assumptions](methods/L24-assumptions.md) → [L08 test](methods/L08-pdsa.md) | Aim owner identifies a consequential unsupported link; safe test can change the decision |
| Cross-boundary transition | [L17 stakeholders](methods/L17-stakeholders.md) → [L31 support](methods/L31-change-support.md) → [L06 plan reset](methods/L06-brief-huddle.md) | Affected accounts inform concrete resourcing; authorised owners accept support/transition commitments |
| Longer-term growth | [L28 development](methods/L28-development-plan.md) → [L12 practice](methods/L12-teach-practice.md) → [L23 cue/action](methods/L23-if-then.md) | Person chooses an opportunity, support and teaching are available, and the learned action is appropriate for a recurring cue |
| One's established mistake | [L32 repair](methods/L32-accountable-repair.md) → [L07 operational learning](methods/L07-debrief.md), if useful | Affected person's boundaries and formal processes are respected; accountability is not deferred until a group meeting |

Do not use a method to manufacture a prerequisite. A public brainstorming format cannot create psychological safety. A vote cannot create authority or establish technical truth. An apology cannot require forgiveness. A premortem cannot certify recovery. A small experiment cannot make an irreversible disclosure safe. A development plan cannot create time without changing real commitments.

Parallel work may be sensible: a qualified safety process can run while the user prepares factual operational context, provided that preparation does not delay protection, expose people or interfere with the formal process.
