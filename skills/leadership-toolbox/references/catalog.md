# Choose the immediate job

Method IDs are stable. Timing is an editorial estimate. There are no global fit scores. Use the [workflow](workflow.md) before committing action when authority, risk or capacity is unresolved.

| Immediate job | Method |
|---|---|
| Transfer a bounded responsibility | [L01 · Outcome delegation agreement](methods/L01-delegation.md) |
| Help someone choose their own next step | [L02 · GROW coaching](methods/L02-grow.md) |
| Discuss observed behaviour and its effect | [L03 · Specific feedback with intent inquiry](methods/L03-feedback.md) |
| Resolve incompatible demands | [L04 · Interest-based negotiation](methods/L04-negotiation.md) |
| Hear ideas beyond dominant voices | [L05 · 1-2-4-All](methods/L05-participation.md) |
| Establish or reset a shared plan | [L06 · Brief and huddle](methods/L06-brief-huddle.md) |
| Learn from a completed episode | [L07 · Structured debrief](methods/L07-debrief.md) |
| Test an uncertain process change | [L08 · PDSA bounded test](methods/L08-pdsa.md) |
| Resolve work that exceeds available capacity | [L09 · Capacity tradeoff](methods/L09-capacity.md) |
| Obtain cooperation across boundaries | [L10 · Evidence and consultation](methods/L10-consultation.md) |
| Check a framing before acting | [L11 · Perspective and evidence check](methods/L11-perspective.md) |
| Develop a missing task skill | [L12 · Teach–Practice–Check-back](methods/L12-teach-practice.md) |
| Surface failure risks before commitment | [L13 · Premortem](methods/L13-premortem.md) |
| Transfer live work with checked receipt | [L14 · Closed-loop handoff](methods/L14-handoff.md) |

When facts change, change the route: capable/available but unclear ownership → L01; lacking skill → L12; overloaded → L09; a live transfer → L14. Contradictory authorised priorities → L04 then L06 after resolution. A reversible unknown process → L08; an irreversible risky commitment → obtain qualified review and consider L13 within that process. A definition request skips the situation gate.

The [guides](guides.md) cover broader situations. [Framework choices](framework-choices.md) explain the optional lens. The [source register](sources.md) records evidence and reuse boundaries.
