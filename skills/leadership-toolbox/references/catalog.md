## Common distinctions

- Missing capacity → L09. Missing demonstrated task skill → L12. Unclear bounded decision rights with a willing supported recipient → L01. Live transfer of work → L14. A reported missed deadline alone proves none of these causes.
- Need an actual other account → L30. Need to check a framing against evidence → L11. Need to establish the problem before accepting a solution → L26.
- Broader participation → L05. Traceable group preference ranking → L18. Evidence-based alternatives and tradeoffs for an accountable decision → L29. A vote cannot resolve technical truth or override a hard constraint.
- Current steps/waits → L21. Possible causes → L20. Theory connecting changes to an aim → L19. Current change enablers/barriers → L22. Which uncertainty to test → L24. Actual bounded learning cycle → L08.
- Immediate skill practice → L12. Longer development pathway → L28. Goal/feedback design → L16. Cue-to-action follow-through → L23.
- Find missing affected groups → L17. Seek genuine cross-boundary cooperation → L10. Plan concrete transition support → L31. Repair one's established mistake → L32, without demanding forgiveness.

Sensemaking tools produce a map, hypothesis set or brief. End by naming what decision/evidence/action that output supports; a completed diagram is not an improvement. Read the full card before recommending a method. Check the strongest alternative and the fact that would switch them. A specialist route or no intervention may be more appropriate than any card.
