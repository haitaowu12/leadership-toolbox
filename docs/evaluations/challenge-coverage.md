# Adversarial acceptance coverage · 0.1.0

These eight challenge areas are author acceptance criteria, separate from the [author illustrations](../../skills/leadership-toolbox/references/examples.md). The [first forward report](forward-2026-10-05.md) and [extension](forward-extension-2026-10-05.md) retain actual responses to independently generated fictional variants and disclose generation/assessment limits. They are model executions, not human field evidence. Exact source-brief scenarios were not copied into the evaluator; the final active-incident coverage explicitly named the scope-gate route and is therefore non-blind.

| Challenge | Required distinction | Related executed evidence |
|---|---|---|
| Novice on an established task | Demonstration, safe practice, observed performance and later work check; overload changes the route | Extension case 1; capacity pair in first report cases 1/2 |
| Capable person missing deadlines under competing sponsors | Make demand/capacity and authorised tradeoff visible; no invented motivation rating | First report capacity pair 1/2; unknown authority/capacity case 7. Multiple-sponsor wording is an author criterion rather than a separately executed exact prompt |
| Active safety-critical incident | Protection, authorised response and accepted coverage before workshop/experiment | Extension case 7; explicitly requested scope-gate coverage, not blind route detection |
| Serious allegation against a manager | Independent reporting/protection route, realistic privacy, no forced mediation or judgement of guilt | Extension case 3 |
| Dominant voices in an access-sensitive group | Preparation/private/pass routes, meaningful input and decision owner; speaking counts are not safety | Extension case 4; exact multilingual configuration remains untested |
| Irreversible cross-team choice with expert disagreement | Separate evidence/preferences, legitimate authorities, documented alternatives/uncertainty and review; no forced consensus or irreversible probe | Extension case 6; first report process reversibility pair 3/4 |
| Improved local delivery with increased downstream burden | Examine balancing effects, honour agreed stop conditions and avoid causal/scale-up claims | Extension case 5 |
| Sent handoff without accepted responsibility | Able authorised recipient, explicit acceptance and retained/escalated coverage if missing | Extension case 2 |

For every situational response, inspect the feasible next action, observed-fact rationale, consequential unknowns, output/owner, later check and stop condition. Several routes may be reasonable when facts are incomplete. These cases do not validate the router as a diagnostic instrument or cover multi-turn behavior, deceptive accounts or every sector.
