## Limits and next user checks

The sample supports the intended routing in these specific responses, not a pass for every situation. There was no no-skill comparator, repeated sampling, varied model family, long dialogue, automatic activation check, or workplace outcome measurement. Cases in the exception context were not independent. Evidence statements were checked against bundled source records rather than independently re-auditing the original research in this execution.

After generation, readable links, task-oriented catalog navigation, numbered steps and provenance placement were improved. The entrypoint, interview, workflow and matching instructions were unchanged from the hashed inputs. These display changes received static/package checks, not a rerun of all conversations. Keep this boundary explicit.
